# Data Cleaning Using SQL

## 📖 About the Project
This project demonstrates SQL techniques for cleaning and preparing datasets for analysis. It includes handling missing values, removing duplicates, standardizing data formats, and ensuring data integrity.

## 🛠️ Tech Stack
- SQL (MySQL)
- Tools: MySQL Workbench

## 📂 Project Files
- `project_of_data_cleaning.sql`: Contains all the SQL queries used for data cleaning.

## 🚀 Features
- Removed duplicate records using `ROW_NUMBER()`.
- Standardized text fields with `TRIM()` and `UPPER()`.
- Transformed date formats using `STR_TO_DATE()`.
- Handled missing values with default replacements.
